Appendix A. Abbreviations for Commands and Other
Values
This topic lists the command names and keywords that can be aliased, followed by the allowable aliases
and abbreviations.
Note:
1. To improve readability, do not use abbreviations in edit macros.
2. ISPF scans the NUMBER macro as a command. If you want to define NUMBER as a program macro and
use the abbreviated form, define the abbreviations as program macros also.
